# Changelog

All notable changes to MuMag2022 Python are documented in this file.

## [0.1.0] - 2026-11-16

### Added

- Stable Python package for field-dependent unpolarized magnetic SANS fitting.
- Weighted non-negative least-squares estimation on the whitened design matrix.
- Exchange-stiffness profiling, uncertainty estimates, residual diagnostics,
  and stability maps.
- Validated legacy input parsing and synthetic example data.
- Browser-native Shiny and Shinylive interface with local in-browser analysis.
- Automated tests and GitHub Pages deployment.
